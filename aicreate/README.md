# aicreate

Landing page for **Enxperts Kids — AI Creator** ("From Idea to Startup"), a 3-month AI program for youth (ages 9–17).

## Files
- `index.html` — the landing page (single file, no build step)
- `assets/` — images (rocket, hero AI artwork, tutor portrait, logo)

## Run locally
Open `index.html` in any browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy
This is a fully static page. Drop the folder on GitHub Pages, Netlify, Vercel, or any static host.

### GitHub Pages
1. Push to `main`
2. Repo → Settings → Pages → Source: `main` / root
3. Visit `https://<user>.github.io/aicreate/`
